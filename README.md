# 🌴 OndaMex

Spanisch für den Strandurlaub in Mexiko: die wichtigsten spanischen Vokabeln und Floskeln – als Lernkarten und Quiz. Läuft komplett im Browser (keine Bibliotheken, keine Datenanfragen, kein Tracking).

**Live:** <https://commanderf.github.io/OndaMex/>

## Funktionen

- **Lernmodus** – Lernkarten mit Tippen zum Aufdecken
- **Quizmodus** – Multiple Choice mit Punktzahl; Rundenlänge einstellbar (Offen/5/10/20 Fragen) mit Auswertung
- **Plausiblere Antwort-Optionen** – Distraktoren bevorzugt aus derselben Kategorie und mit ähnlicher Form, damit die richtige Antwort nicht am Format erkennbar ist
- **Sprachausgabe** – 🔊-Button an der spanischen Karten-Seite liest das Wort/die Floskel vor (Web Speech API des Geräts)
- **Richtung** – DE → ES und ES → DE umschaltbar
- **Kategorien** – Begrüßung, Restaurant, Strand, Ausflug, Einkaufen, Notfall, Zahlen (oder „Alles“ gemischt)
- **Dark Mode** – folgt der Systemeinstellung
- Optimiert für Handy und Desktop
