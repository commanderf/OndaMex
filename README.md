# 🌴 Spanisch für Mexiko

Kleine Web-App für den Strandurlaub in Mexiko: die wichtigsten spanischen Vokabeln und Floskeln – als Lernkarten und Quiz. Läuft komplett im Browser (eine einzige HTML-Datei, keine Bibliotheken, keine Datenanfragen).

**Live:** `https://commanderf.github.io/spanisch-mexico/` (nach dem ersten Deploy)

## Funktionen

- **Lernmodus** – Lernkarten mit Tippen zum Aufdecken
- **Quizmodus** – Multiple Choice mit Punktzahl
- **Richtung** – DE → ES und ES → DE umschaltbar
- **Kategorien** – Begrüßung, Restaurant, Strand, Ausflug, Einkaufen, Notfall, Zahlen (oder „Alles“ gemischt)
- **Dark Mode** – folgt der Systemeinstellung
- Optimiert für Handy und Desktop
